# 포켓몬 IV 랭크체커

포켓몬GO PvP(리틀/슈퍼/하이퍼/마스터 리그) IV 랭크체커. 카카오톡 봇(메신저봇R)과 PC용 HTML 버전 두 가지로 제공한다.

## 파일 구성

- `포켓몬랭크봇.js`: 메신저봇R용 카카오톡 챗봇 스크립트
- `포켓몬랭크봇.html`: 같은 계산 로직을 브라우저에서 그대로 쓸 수 있는 PC용/모바일용 버전(네트워크 호출만 `fetch`로 교체)
- `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`: 위 HTML을 폰 홈 화면에 앱처럼 설치할 수 있게 해주는 PWA 구성 파일
- `포켓몬랭크봇프롬프트.txt`: 이 프로젝트를 만들 때 썼던 최초 요청 프롬프트 기록

## 사용법

### 카카오톡 (메신저봇R)

```
?포켓몬 <한국어이름> <IV공격> <IV방어> <IV체력> <CP> [최대레벨]
```

예시:
```
?포켓몬 파이리 0 15 14 395
?포켓몬 파이리 0 15 14 395 40    (XL 사탕 없이 40레벨까지만 키울 예정이면)
```

- `[최대레벨]`은 생략 가능. 생략 시 50(XL 사탕 있음 기준)으로 계산. 40을 넣으면 XL 사탕 없이 40레벨까지만 키운다는 가정으로 등수/CP를 계산한다.
- 이름은 콜론(:)이나 영문 대소문자가 달라도 찾는다. 예: `타입널` = `타입:널`, `폴리곤z` = `폴리곤Z`.
- **니드런은 암수가 따로 있다.** `니드런암`/`니드런수`로 입력한다(`암컷`/`수컷`, `♀`/`♂`도 된다). `니드런`만 쳐도 입력한 IV로 그 CP가 정확히 나오는 쪽이 하나면 알아서 골라 계산하고, 결과 맨 위에 `※ '니드런'은 암수가 따로 있어서, CP 486에 맞는 니드런♀로 계산했습니다.` 같은 안내가 붙는다. 암수 둘 다 그 CP가 나오거나 둘 다 안 나오면 `니드런암` 또는 `니드런수`로 다시 입력하라고 안내한다.
- `?포켓몬디버그 <한국어이름>`: 이름을 못 찾을 때 원인 진단용 명령어.
- `?포켓몬테스트`: 봇이 살아있는지 확인.

**설치 시 확인할 것**: 메신저봇R에서 이 스크립트의 "네트워크 사용" 권한을 반드시 켜야 한다. 파일 맨 위쪽 `ALLOWED_ROOMS` 변수에 방 이름을 넣으면 그 방에서만 응답한다(빈 배열 `[]`이면 모든 방에서 응답).

### PC용 HTML

`포켓몬랭크봇.html` 파일을 그냥 브라우저로 열면 된다(서버 필요 없음). 입력창에 `<한국어이름> <IV공격> <IV방어> <IV체력> <CP> [최대레벨]`을 카카오톡과 똑같은 형식으로 입력하고 "계산" 버튼(또는 Enter). "지우기" 버튼으로 입력/결과를 초기화할 수 있고, 이름을 못 찾으면 "진단 보기"로 원인을 확인할 수 있다.

### 모바일 웹앱(PWA)으로 설치

이 HTML은 PWA(Progressive Web App)로도 구성돼 있어서, 폰 브라우저로 열고 "홈 화면에 추가"를 하면 아이콘이 깔리고 앱처럼(주소창 없이) 실행된다.

**배포 주소**: https://questline-dev.github.io/pokemon-rank-bot/포켓몬랭크봇.html (2026-09-14, 개인 계정 노출 방지를 위해 `questline-dev` 조직으로 이전 + 히스토리 새로 시작)

- **설치되려면 HTTPS로 호스팅돼 있어야 한다.** `file://`로 직접 열면 서비스워커가 등록되지 않아 설치 버튼이 안 뜬다. 위 GitHub Pages 주소를 쓰면 된다. 코드를 고친 뒤 `git push`만 하면 1~2분 안에 자동 재배포된다.
- Android(Chrome): 사이트 접속 후 메뉴 → "홈 화면에 추가" / "앱 설치".
- iOS(Safari): 공유 버튼 → "홈 화면에 추가".
- 설치 후에도 데이터(포켓몬 종족값 등)는 매번 인터넷에서 최신으로 받아오므로, 오프라인에서는 화면만 뜨고 조회는 안 된다.

## 반환 형식 읽는 법

```
● 파이리 0 15 14 395 : lvl16

- Charmander (파이리) / S858[lvl50 cp977] / H858[lvl50 cp977] / M858[lvl50 cp977] / 🔴L55[lvl20 cp494]
- Charmeleon (리자드) / S18[lvl39.5 cp1494] / H761[lvl50 cp1701] / M761[lvl50 cp1701] / L42(X)
- Charizard (리자몽) / S580[lvl19 cp1466] / H31[lvl34.5 cp2488] / M598[lvl50 cp3053] / L194(X)
- Mega Charizard X (리자몽) / S1510(X) / H3[lvl24 cp2496] / M517[lvl50 cp4116] / L65(X)
- Mega Charizard Y (리자몽) / S1292(X) / H35[lvl20.5 cp2486] / M401[lvl50 cp4799] / L2047(X)
```

- 첫 줄(`●`)은 입력값 그대로 + 입력한 종의 실제 현재 레벨(입력 CP로 역산).
- 이후 각 줄은 "이 개체가 갈 수 있는" 진화 단계(이미 진화했으면 이전 단계는 안 보임. 메가진화는 포함)와, 각 리그(S=슈퍼 1500 / H=하이퍼 2500 / M=마스터 무제한 / L=리틀 500)에서의 등수.
- `[lvlXX cpXXXX]`는 그 리그 CP상한 안에서(최대레벨까지) 최선으로 키웠을 때의 레벨/CP.
- `(X)`는 "지금 실제 레벨로 파워업하면 그 리그 CP상한을 이미 넘어버려서 참전 불가"라는 뜻. 파워업으로 레벨을 낮출 수 없다는 실제 게임 규칙을 반영한 것.
- 🔴(카톡)/빨간 굵은 글씨(HTML)는 250위 이내(상위 6.1%) 강조 표시.
- 호바귀/펌킨인처럼 "사이즈"(Small/Average/Large/Super)가 종족값을 바꾸는 포켓몬, 자시안/미니오르처럼 "폼"이 여러 개인데 어느 쪽이 기본인지 애매한 포켓몬은, 봇이 실제 어느 폼/사이즈인지 알 방법이 없어서 후보를 전부 보여준다. 본인 CP와 정확히 일치하는 줄이 실제 개체다.

자세한 설계 배경과 알려진 한계는 `유지보수노트.md` 참고.
